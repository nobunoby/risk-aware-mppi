# Risk-aware MPPI project page

Static academic project page. Preview with `python3 -m http.server 8000`. The supplementary video is hosted at `assets/videos/TCST_supplementary_video.mp4`.

The manuscript is in preparation. Once a preprint exists, add the Paper and arXiv links at the marked comment in `index.html`, update the status note, and add the formal BibTeX citation at its marked comment. Recheck figures, numbering, results, and the research overview against the final manuscript. Do not add the manuscript PDF or source files to this repository.
