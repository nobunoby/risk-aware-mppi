# Academic project page

Private manuscript project page. Figures are exports of the supplied manuscript source PDFs, verified against the supplied PDF (Figs. 1–4). Do not publish or enable Pages without authorization.

Static HTML; run `python3 -m http.server 8000` to preview.

Based on the [Academic Project Page Template](https://github.com/eliahuhorwitz/Academic-project-page-template), with elements adopted from [Nerfies](https://nerfies.github.io/).
